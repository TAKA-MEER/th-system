### 方法3: 手元で再生成する

```bash
# VOICEVOX Engine を起動 (Nemo の9話者が含まれる)
docker run -d --rm --name voicevox -p 50121:50021 voicevox/voicevox_engine:cpu-latest

# 生成 (--mp3 を外すと WAV。話者を変えるだけなら --all-speakers で男声も出る)
python3 th_ws/scripts/voice_audition.py --out docs/voice-audition --mp3
```

## 選ぶときの観点

フレーズは性格の異なるものを選んである。

| ID | 文言 | 何を見るか |
| --- | --- | --- |
| A1 | 停止。LiDAR 異常 | 英字を含む。カナ指定（「ライダー」）で正しく読めているか |
| A3 | 緊急停止 | 最短 0.7 秒。短くても潰れず聞き取れるか |
| C4 | 逃げ場なし。離れて | 最も緊急度が高い。切迫感が出るか |
| D1 | 復旧。再開操作を | 復帰系。安心感が出るか |
| N27 | 再発見。追従再開 | デモの山場 |
| N4 | 捕捉。前方 3 メートル | 数値を含む。数値は分割合成する対象 |

合成条件は**話速 1.15 倍・抑揚 0.8 倍**（機器アナウンス寄りに寄せた設定、VISION.md §7.5）。
話者を決めた後、この値自体も調整の余地がある。

判断の前提として、この音声は**オリジナルキャラクターの声**として使う想定。
VOICEVOX Nemo はキャラクターとしての人格を持たない音声ライブラリなので、
既存キャラクターとの同一性の問題が起きない（それが Nemo を選んだ理由）。
