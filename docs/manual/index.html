画面の構成 例：S-11 手動走行

どの画面も、上にヘッダ（画面名・モード・異常・非常停止）、左に主な表示、右に操作カードと手動操作が並びます。

  1. 画面名いま開いている画面。ヘッダで一番大きい文字。
  2. モード機体がいまどのモードにいるか。画面名と違うことがある。
  3. フォルト表示正常なら緑の点と「正常」。異常のときは原因と対処を 1 行で出す。
  4. 非常停止どの画面でも右上。押すと速度指令を 0 にする（6 章）。
  5. 終了どの画面でも左上（タブの左）。そのモードを抜けてメインメニューへ戻る。
  6. タブ左側の表示を切り替える。
  7. 操作カード停止・走行・保存など、その画面の主な操作。並ぶボタンは画面ごとに違う。
  8. 状態一時停止中・走行中・記録中など、いまの状態。
  9. スティック触れている間だけ動く。倒した向きと量で前進・後退・旋回。
  10. 速度スライダ0〜100%。100% で手動の上限いっぱい。
  11. 速度プリセット低速 27%・中速 55%・高速 100%（前進の上限 0.55 m/s に対する割合）。

どの画面でも共通の決まり

  • 押しても何も起こらないことがある。いまの状態で受け付けられないボタンは、何も表示されずに無視されることがあります。 故障ではなく「まだその操作をしてよい状態ではない」と考えて、状態の表示を確かめてください。
  • スティックやキーを離すと、通常の加減速で減速して止まります。最高速からは約 0.6 m・約 2.2 秒かかります。 すぐ止めたいときは非常停止を押します。
  • 真横に倒すその場旋回は速度プリセットの影響を受けません（上限 1.0 rad/s）。PC で開いたときは WASD か矢印キーでも走れます。
詳しくは：使い方.md §3「画面と操作」・§3-1「ボタンの場所」・§3-2「手動走行」

2. 起動と運用の終了

起動する S-00 接続確認

  1. ロボットとラズパイの電源を入れ、PC をロボットの AP につなぐ（屋内は PC に USB 無線ドングルを挿すと、数秒で 5GHz の th-rpi-5g に自動でつながる）。
  2. PC で cd th_ws && ./start.sh。このターミナルは開いたままにする（閉じるとロボットが止まる）。
  3. タブレットで http://192.168.5.50:5173 を開く（PC で見るだけなら http://localhost:5173）。
  4. 下の接続確認の画面で、総合が「運用に入れます」になったら メインメニュー画面へ。
  1. 疎通確認機器ごとに独立に判定する（✓ 疎通／× 未接続）。行の下に最後に受信してからの時間など。
  2. 必須の機器「必須」の行（ESP32・ラズパイの LiDAR・PC）が全部 ✓ になるまで先へ進めない。
  3. 任意の機器カメラ・リードデバイス。つながっていなくても進めるが、それを使う走行方式は選べない。
  4. 総合必須がそろうと「運用に入れます」。
  5. メインメニュー画面へ必須がそろうまで出ない。
  6. 始業点検の自動判定起動のたびに行う簡易判定（非常停止ボタン・IMU・LiDAR）。要確認でも運用には入れる（警告だけ）。
起動直後について起動直後に出るフォルトは、1〜2 分で消えるのが正常です。 既定の stage:=4 では、起動直後に一時的に非常停止のウィンドウが出ることがあります。S-00 で全機器が「疎通」になってから、ウィンドウの「解除」を 1 回押します。
詳しくは：使い方.md §1「起動する」・§2「起動後の健全性確認」

3. 試験場の外を走る

手動走行 S-11 モード：手動走行

メインメニュー → 手動走行。右のスティックで動かします。手を離すと減速して止まります。

  1. 障害物前方の障害物の警告。
  2. 接近の警告自動ブレーキ OFF のとき、ON なら減速が始まる距離まで近づくと出る。速度は自動では落ちないので自分で止める。
  3. 自動ブレーキいまの状態（ON／OFF）。
  4. 切替ボタンON にする／OFF にする（次のページ）。
  5. 後退後方は LiDAR の死角なので、後退の速度は制限される。
  6. 停止走行をやめて一時停止。
  7. スティック触れている間だけ動く。
  8. 速度スライダ0〜100%。
  9. 速度プリセット低速・中速・高速。
  10. キー操作PC では WASD か矢印キーでも走れる。

走らせ方

  • 自動で止まるのは、進行方向 ±29 度の範囲に物があるときだけです。真横の壁では止まりません。止まるのは機体の前面から約 15 cm まで近づいたときです。曲がり角では正面の壁に寄せすぎないよう、少し早めに回ります。
  • スティックを一気に倒しても、急発進・急停止はしません（加減速に制限があります）。障害物のブレーキと非常停止はこの制限を通らず、すぐ効きます。
  • 真横に倒すその場旋回は、速度プリセットを低速にしてもキビキビ回ります（上限 1.0 rad/s）。
詳しくは：使い方.md §3-2「手動走行」・§3-3「走らせ方のコツ」

自動ブレーキ S-11・S-13

障害物に近づいたとき、自動で減速・停止する働きです。手動走行・教示（手動）の「障害物」カードで切り替えます。

  1. 自動ブレーキ ONボタンは OFF にする に変わる
  1. やめるON のまま
  2. OFF にする確定する
項目内容
既定値試験場外の手動走行は OFF（減速せず、画面の警告だけ）、試験場内の画面では ON。手動走行に入るたびに既定へ戻る（前回の選択は引き継がない）
切り替え方OFF にする／ON にする。ON → OFF のときだけ確認が出る。OFF → ON は確認なし。表示は、機体が受け付けてから切り替わる
OFF のあいだ障害物に近づいても減速しない。ON なら減速が始まる距離で「障害物に近づいています（自動ブレーキ OFF のため減速しません）」と出る。警告を見たら自分で止める
OFF でも変わらないもの非常停止、異常による停止、速度上限、後退速度の制限、LiDAR や機体との通信が途絶えたときの停止。機体からの状態が途絶えると ON に戻って止まる
切り替えられる場面手動走行・教示（手動）と、手動操作パネルで介入している間だけ。追従・再生などの自律走行では無効にできない
画面を離れたとき画面を閉じる・別のアプリに切り替えるなど、操作している画面が無いと機体が判断している間は ON（戻ると選んだ設定に戻る）
OFF にするときはOFF のあいだは、障害物に近づいても機体は速度を落としません。周囲に人や物が無いことを確かめ、いつでも止められる位置で操作してください。音は出ません。
詳しくは：使い方.md §3-2「自動ブレーキ」
3. 試験場の外を走る使い方（図解）

教示（手動）① 経路を選んで記録を始める S-13

スティックで走らせた通り道を経路として記録します。メインメニュー → 教示（手動） → 教示 タブ。

  1. 教示タブ経路の選択と記録の状況。走らせるときは「走行」タブ。

  1. 開発モードを有効にする有効にしただけでは通常の運用と同じ。
  2. 無視する警告外す項目を 1 つずつ選ぶ。項目の無いもの（物理の非常停止ボタン・ESP32 のウォッチドッグ・画面の非常停止など）は通常どおり効く。
  3. いま無視しているもの機体が実際に外している項目。
開発モードは試験では使いません開発者が検証に使うものです。有効にすると、機器がそろっていなくても起動の確認を通せてしまいます。ヘッダに「開発モード」の札が出ている間は通常の運用状態ではありません。意図せず有効になっていたら無効にしてください。

機器がそろわず接続確認（S-00）で止まったときは、S-00 の 開発モードの設定 からこのタブに入れます（2 章）。開発モードで通した結果は、通常の運用の結果と取り違えないようにします。

画面の非常停止ボタンを押したとき

右上の 非常停止 を押すと、速度指令が 0 になります。画面は変わらず、上にウィンドウが乗ります。

  1. 非常停止押したあとは色が変わる。
  2. フォルト表示「非常停止中」。
  3. 非常停止のウィンドウ非表示 で隠せる（非常停止は続く）。
  4. 解除バー画面の非常停止を押したときだけ下端に出る。非常停止を解除。
  1. メインメニューへ待機に戻る。最初からやり直す
  2. 元のモードに戻る止まる直前のモードの一時停止に戻る
  • 「元のモードに戻る」を押しても、機体は動き出しません。走らせるには改めて 走行（教示再生は 再生）を押します。
  • 位置合わせ・確認・選択の途中で止まった場合は、その入口からやり直します（呼び寄せは 2 点指示から、始業点検・校正は一覧から）。
  • 安全監視（重大な異常）で入った非常停止には、解除バーは出ません。ウィンドウに異常の名前と対処が出て、原因が消えるとウィンドウの 確認（または 元のモードに戻る）で戻れます。原因が消えていない間はボタンが出ません。
  • 走行中に勝手に出たときは、何が出たかを記録して報告します。
詳しくは：使い方.md §3-5「非常停止中の窓が出たら」

手押し（物理の非常停止ボタンを押したとき）

機体の物理の非常停止ボタンを押すと駆動が切れ、「手押し」になります。人が機体を押して運べます。

  1. 画面の非常停止灰色。手押しの間は押しても効かない。
  2. フォルト表示「手押しモード（物理非常停止ボタン押下中）」。
  3. 手押しのウィンドウ解除のしかた（機体後部の赤いボタンを右へひねる）が出る。
  1. 解除されました
  2. 再開する（すぐには動き出しません）止まる直前のモードの一時停止に戻る
  3. 再開しない（待機に戻る）最初からやり直す
  • 「再開する」を押しても機体は動き出しません。走らせるには改めて 走行 を押します。位置が変わったので、その後の走行は経路を計画し直します。
  • 手押しの間に、暴走と判定されて非常停止に落ちることはありません（ボタンを戻したあとは通常どおり判定します）。ESP32 との通信が切れたときは、ボタンの状態が分からず解除できない旨がウィンドウに出ます。
詳しくは：使い方.md §3-5「手押しからの戻り方」

異常のウィンドウ

走行中に異常（例：LiDAR の点群が途絶えた）が起きると、機体は止まり、異常のウィンドウが出ます。

  1. フォルト表示原因と対処を 1 行で。
  2. 異常のウィンドウ原因と対処。解決すると、このウィンドウが再開の選択肢に変わる。
  3. 非表示ウィンドウを隠す（異常は続いている）。
  1. 再表示 ▲押すと異常のウィンドウをもう一度出す。
  • 一瞬だけ出て自然に消える異常では、ウィンドウは出ません（単発の誤検知を無視するため）。
  • 走行中にタブレットを閉じた・回線が切れたときも、このウィンドウに「操作端末が離れたため一時停止しました」と出ます。
詳しくは：使い方.md §3-5・§3-4「走行中にタブレットを閉じる／切れると一時停止になる」

異常が解決したら

原因が消えると、同じウィンドウが「異常が解決しました」に変わり、戻り方を選べます。

  1. 解消した異常種別・続いた時間・始まった時刻。0.1 秒で解消しても、ボタンを押すまで残る。同じ種別が続いたときは「ほか 2 回」
  2. いいえ元のモードの一時停止に戻る
  3. はい元のモードで走行を再開する
  1. 確認元のモードの一時停止に戻る（例：自己位置を見失った）
ボタン戻り先
はい元のモードで走行を再開する。盤前などへの移動では、走り出す前に経路の先 1.5 m が空いているか確かめ、塞がれていれば止まって待つ
いいえ／確認元のモードの一時停止に戻る。走らせるには改めて 走行（再生）を押す
  • どちらを選んでも、待機（メインメニュー）には戻りません。違うのは、すぐ走り出すかどうかだけです。
  • 手動走行などで 確認 を押すと、ウィンドウは閉じて一時停止のまま残ります。
