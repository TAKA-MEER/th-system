# 自律測定（測定機能との連携）

[Spec.md](Spec.md) の詳細。**測定機能（fk-system。別リポジトリ `../fk-system`）の指示を受けて動くときの、本システムの振る舞い。**

測定機能そのもの（何を・どう測るか、どこへ行くかの判断）の正は fk-system の spec（`../fk-system/docs/plan/spec/Spec.md` §1.1.2・§1.2、`FD-12`・`FD-13`）。
**ここには本システムの振る舞いだけを書き、fk-system の決まりは写さない。**
2026-11-01、fk-system の実装管理担当から届いた申し送り（[Spec-open.md](Spec-open.md) §8）を、ユーザーの続行承認を得て反映した。

---

## 0. 骨子

**判断は測定機能、実行は本システム。**測定機能が「どこへ行くか・経路を引き直すか・盤前でどう動くか」を決め、
本システムが経路の計画・走行制御・停止を行う。

| 項目 | 方針 |
| --- | --- |
| 何か | 盤の配置を測定機能が推定し、使用者が選んだ盤へ自律で移動して測る機能。**お立会試験以外でも使う、応用的・挑戦的な機能**（ユーザー決定 2026-11-01） |
| モード | **`AUTO_MEASURE`**（[Spec-modes.md](Spec-modes.md) §2.5） |
| 試験場内の動作との関係 | **ほとんど別物。**前日の地図もピンも使わず、**入るたびに地図を作りながら走る**（§4） |
| 測定機能の権限 | **このモードの中に限り、試験員の操作と同等に扱う**（§2） |
| 安全 | **非常停止・障害物の停止・速度の制限・異常時の停止は、試験場内と同じに効く。**測定機能の指示で緩むものは無い |

### 0.1 試験場内の動作との違い

| 項目 | 試験場内（`PANEL_NAV` など。[Spec-onsite.md](Spec-onsite.md)） | 自律測定（`AUTO_MEASURE`） |
| --- | --- | --- |
| 地図 | 前日に作った会場地図が必須（§4.0.3） | **入るたびに新しく作る。**会場地図・ピン・経路地図は使わず、上書きもしない |
| 地図の凍結 | する（§4.0.2） | **しない**（地図を作りながら走る） |
| 行き先 | 試験員がピンを選ぶ／その場で呼ぶ | 測定機能が目的地を指示する |
| 別のルートを探す | 試験員が「再検索」を押したときだけ（§6） | **測定機能が「経路の再計算」を指示したときだけ。**本システムが自分の判断で別のルートを探さないのは同じ |
| 発進・再開 | 試験員の操作 | 測定機能の発進の指示 |
| 盤前の動き | 到着後の向き合わせだけ。低速並進は無い | 測定機能の指示で、**その場旋回（角度）と低速並進（左右と距離）**（§5） |
| 速度上限 | 場内 `v_slow` | 場内 `v_slow`。**測定機能が指定すれば、その小さい方**（§3） |
| 自己位置を見失ったとき | [Spec-safety.md](Spec-safety.md) §3.5.0 | **同じ検知・同じ閾値**（§4.3） |

## 1. 入り方と抜け方

| 項目 | 振る舞い |
| --- | --- |
| 入口 | **メインメニュー画面の「自律測定」ボタン**（[Spec-webui.md](Spec-webui.md) §3.2） |
| 明示操作 | 押すと**「自律動作を許可しますか」のダイアログ**を出す。**「許可する」を押したことが明示操作**（SD-8。ユーザー決定 2026-11-01）。「許可しない」なら `IDLE` のまま |
| 入れる条件 | 他のモードと同じ（必須 3 者の疎通・重大フォルト無し・非常停止の解放）に加え、**測定機能と通信できること**。満たさなければボタンを押したときに理由を出す |
| 入った直後 | **止まったまま測定機能の指示を待つ**（`WAIT`）。許可しただけでは動き出さない |
| 測定機能の画面へ | 本システムの画面の「測定機能の画面へ」で移る。**画面を移るだけで、モードは変わらない**（`SM-3.1.1-17`） |
| 抜け方 | 本システムの画面の**「自律測定を終了」でいつでも `IDLE` へ**（「終了」＝`SM-3.1.1-10`）。**抜けただけで動き出さない** |
| 測り終えたら自動で抜けるか | **未定**（[Spec-open.md](Spec-open.md) `O-a8`） |
| 作った地図 | **保存しない**（入るたびに作り直すため）。抜けたあと試験場内で動くなら、会場地図を開き直す（`SM-3.1.2-119` がそれまで自律移動を拒否する） |

## 2. 測定機能の権限（fk-system `FD-12`）

**このモードの間に限り、測定機能の次の指示を試験員の操作と同等に扱う。**モードを抜けると解ける。

| 同等に扱う指示 | 試験員の操作に当たるもの |
| --- | --- |
| 目的地 | 行き先を選ぶ |
| 経路の再計算 | 「再検索」 |
| 発進（一時停止からの再開を含む） | 「走行」 |
| 停止 | 「停止」 |
| 中止 | 「中断」 |
| 盤前の旋回・並進 | 盤前での手動の位置合わせ |
| 速度・加速度の上限の指定 | — （本システムの上限を**下げる方向にだけ**効く。§3） |

**同等に扱わないもの（人が行う）:**

| 操作 | 理由 |
| --- | --- |
| 非常停止・手押しの解除 | 解除は機体のそばにいる人の確認を前提にしている（[Spec-safety.md](Spec-safety.md) §4） |
| 異常ウィンドウへの応答（「確認」） | 異常が解消したことを人が確かめる。§7 |
| 設定値の変更 | SD-9（変更できるのは停止中・`IDLE` と `PREP` だけ）。測定機能の速度・加速度の指定は設定値を書き換えず、その動きの上限を下げるだけ |

## 3. 受ける指示と返す状態

| 指示 | 本システムの振る舞い |
| --- | --- |
| **目的地**（位置と向き） | 地図を作りながら経路を計画して走る（§4）。着いたら向きを合わせ、**向きまで合って到着**とする（試験場内と同じ到着の定義。[Spec-onsite.md](Spec-onsite.md) §2.1.1） |
| **経路の再計算** | いまの地図で経路を引き直し、走り直す |
| **発進** | 一時停止から再開する。**走り出す前に手前の経路を確かめる**（§4.2） |
| **停止** | 一時停止（`PAUSE`） |
| **中止** | 今の目的地・指示を捨て、その場で止まって次の指示を待つ（試験場内の「中断」に当たる） |
| **旋回**（角度） | その場で指示の角度だけ回る（§5） |
| **並進**（左右と距離） | 旋回と走行を組み合わせて横へずれる（§5） |
| **速度・加速度の上限** | 以後の動きに効かせる。**本システムの上限との小さい方を使い、上げる方向には効かない**（SD-9 と両立させるため。昇降機を上げたまま動くときに使う。§5.1） |

**指示を受けられない状態**（非常停止中・手押し中・一時停止中の目的地の選び直しなど）では**拒否し、理由を返す。**
受けられる状態と遷移の正は [Spec-modes.md](Spec-modes.md) §3.1.2（`SM-3.1.2-120`〜）。

**返す状態:** 到着／指示の完了と拒否（理由つき）／モードと状態（`WAIT`・`NAV`・`ALIGN`・`BLOCKED`・`ADJUST`・`PAUSE`）／
塞がれて止まっていること／一時停止とその理由／フォルト／自己位置と作りかけの地図。

## 4. 地図を作りながら走る

### 4.1 地図

| 項目 | 振る舞い |
| --- | --- |
| 作り始め | **モードに入るたび、新しい地図で作り始める**（fk-system `FD-13`） |
| 触れないもの | **試験場内の会場地図・ピン・教示の経路地図**。読み込まず、上書きもしない |
| 凍結 | **しない**（[Spec-onsite.md](Spec-onsite.md) §4.0.2 は試験場内の決まり） |
| 地図のない所 | **推測で経路を引いて動き出す。**地図が育つにつれ、測定機能が経路の再計算を指示する |

### 4.2 経路の検査（ユーザー決定 2026-11-01）

**手前だけ、地図ができていて通れることを確かめる。その先の地図のない所は推測の経路として通す。**

| 項目 | 振る舞い |
| --- | --- |
| 確かめる範囲 | **機体の現在位置から経路に沿って 1.5 m**（[Spec-onsite.md](Spec-onsite.md) §6.3 と同じ長さ） |
| 確かめること | その範囲が**地図のできている所**で、**0.55 m 角の機体の形で壁・障害物に当たらない**こと（[Spec-onsite.md](Spec-onsite.md) §6.1.1 と同じ機体の形） |
| その先 | 地図のない所も推測の経路として通す（地図のある所の壁・障害物には当たらないこと） |
| いつ確かめるか | **走り出す前と、走行中も一定周期（約 0.5 秒）で** |
| 通れない・まだ地図が無いとき | **止まって `BLOCKED` に移り、測定機能に知らせる。**測定機能の経路の再計算を待つ。**止まっている間、その場で旋回しない**（[Spec-onsite.md](Spec-onsite.md) §6.3 と同じ理由。角が振れる） |
| 手前が空いたとき | 残りの経路で走り直す（別のルートは探さない。探すのは測定機能が再計算を指示したとき） |
| 障害物マップが届かない・古いとき | [Spec-onsite.md](Spec-onsite.md) §6.3 と同じ（止まっているなら空いていないものとして待つ。走行中は止めず、障害物リミッタに任せる） |
| 安全装置との関係 | この検査は**止まって待つための**もので、安全装置の代わりではない。地図に載らない障害物は障害物リミッタが止める（[Spec-safety.md](Spec-safety.md) §2） |

### 4.3 自己位置を見失ったとき（ユーザー決定 2026-11-01）

**試験場内と同じ検知・同じ閾値を使う**（[Spec-safety.md](Spec-safety.md) §3.5.0 の A・C・B′）。

| 項目 | 振る舞い |
| --- | --- |
| 監視する範囲 | **モード全体**（`WAIT` で止まっている間も含む。[Spec-safety.md](Spec-safety.md) §3.5.0 の表） |
| 推定が止まる・ノードが死ぬ（A・C） | `LOCALIZATION_LOST` で非常停止 |
| 位置が飛ぶ（B′） | **1.0 m／0.5 rad を超えたら `LOCALIZATION_LOST` で非常停止。**超えない補正は正常として走り続ける。地図が補正されて経路が合わなくなったら、測定機能が再計算を指示する |
| 地図を作りながら走ったときの飛びの大きさ | **実機で測る**（[Spec-open.md](Spec-open.md) `O-c8`）。止まりすぎるなら見直す（SD-7。測る前に緩めない） |
| 入るときの推定の立て直し | 新しい地図で作り始めるための立て直しは**計画的な再起動**として扱う（[Spec-safety.md](Spec-safety.md) §3.5.0「計画的な再起動は異常ではない」） |

## 5. 盤前の動き

**盤前の低速並進は本システムの範囲に入れる**（旧 `O-d3`。ユーザー決定 2026-11-01）。
クローラは横に動けないので、**横へのずれは旋回と走行の組み合わせで本システムが作る。**

| 項目 | 振る舞い |
| --- | --- |
| その場旋回 | **測定機能が角度を指示する。**本システムはその角度だけ回り、終わったら完了を返す |
| 低速並進 | **測定機能が左右と距離を指示する。**旋回と走行の組み合わせは本システムが決めて制御する |
| 速度の上限 | **`v_jog_panel`**（盤前のジョグと同じ。盤との接触を避ける。[Spec-modes.md](Spec-modes.md) §6）。測定機能の指定があればその小さい方 |
| 精度 | いまの到着の許容差（±0.12 m／±0.12 rad。[Spec-onsite.md](Spec-onsite.md) §6.2）が目安。**旋回の角度の精度は、不感帯を測ることで改善できる見込み**（fk-system の見立て）。クローラはその場旋回で最も滑る（[Spec-safety.md](Spec-safety.md) §3.5.0 の実測）。要る精度は fk-system `FK-V4` |
| **旋回の前の確認**（ユーザー決定 2026-11-01） | **旋回の指示を受ける前に、機体の角が描く円（外接半径 0.389 m）の中に、障害物マップかスキャンの障害物があるかを確かめる。あれば旋回せず、理由を返す**（`WAIT` のまま）。障害物リミッタは前進は止めるが旋回は通す（[Spec-onsite.md](Spec-onsite.md) §6.3）ため。本システムの案を fk-system 側でも採った（fk-system `FK-X7`。[Spec-open.md](Spec-open.md) F-47） |
| 並進で盤に当てない条件 | **未定**（[Spec-open.md](Spec-open.md) `O-a9`。fk-system `FK-X7`） |

### 5.1 昇降機を上げたまま動くとき

| 項目 | 振る舞い |
| --- | --- |
| 本システムが知っていること | **昇降機の高さを知らない**（昇降機は hve-system。本システムと連動しない） |
| 速度・加速度 | **測定機能が指定する上限に従う**（§3。本システムの上限との小さい方） |
| 上限の値 | **未定**（fk-system `FK-V5`） |
| 注意 | **障害物・非常停止・通信途絶による停止は鈍らせない**（[Spec-safety.md](Spec-safety.md) §3）。加減速 0.4 m/s² と S 字の値は昇降機を最低にした状態で決めたもの。**上げたまま急停止したときに耐えるかは、本システムでは保証しない。**測定機能が上限を決めるときに考える |

## 6. 画面と在席

| 項目 | 振る舞い |
| --- | --- |
| 本システムの画面 | **S-60 自律測定**（[Spec-webui.md](Spec-webui.md) §3.16）。**常設ヘッダ（非常停止を含む）・「測定機能の画面へ」・「自律測定を終了」**だけを置く。ふだんは測定機能の画面を前に出して使う |
| 測定機能の画面 | 本システムとは別のポート。**本システムの中にいるような操作性にする**（fk-system 側で作る） |
| ゾーン | **`IN`（場内）。**速度上限 `v_slow`・自動ブレーキ ON |
| 在席（[Spec-safety.md](Spec-safety.md) §6.2） | **このモードの間は、測定機能の画面が前面にある端末も「使用中」に数える。**そのため**測定機能の画面から本システムへ、在席と画面（ゾーン `IN`）の申告が届く**ことが要る（fk-system への申し送り。[Spec-open.md](Spec-open.md) §8）。届かなければ使用中の端末が 0 台になり、速度上限は停止（[Spec-modes.md](Spec-modes.md) §7.1）。走行中なら一時停止に落ちる（[Spec-safety.md](Spec-safety.md) §6.2.2） |
| 非常停止（SD-3） | **操作者が見ている画面が測定機能の画面でも、本システムの非常停止が何にも覆われずに押せる**こと。測定機能の画面での見せ方は fk-system `FK-U1`（未定） |
| 異常・案内のウィンドウ | 本システムの画面に出す。測定機能の画面でどう知らせるかは**未定**（[Spec-open.md](Spec-open.md) `O-a8`） |

## 7. 異常・ジョグ・通信断

| 状況 | 振る舞い |
| --- | --- |
| 回復フォルト | `PAUSE` に落ちる（`SM-3.1.1-03`）。解消したら**「確認」1 択で `PAUSE` のまま**（[Spec-modes.md](Spec-modes.md) §6）。**戻っただけでは動かない。**走り出すのは測定機能の発進の指示（`SM-3.1.2-130`） |
| 重大フォルト・非常停止・手押し | 他のモードと同じ（`ESTOP`／`CARRY`）。解除と応答は人が行う（§2） |
| **測定機能との通信が途絶えた・測定機能が落ちた** | **止まって `PAUSE` に落ちる**（回復フォルトと同じ扱い。`SM-3.1.2-133`）。通信が戻っても、**測定機能の発進の指示があるまで走らない**。途絶とみなすまでの時間は (b)（[Spec-params.md](Spec-params.md)） |
| 人のジョグ | **人と測定機能のどちらを優先するかは未定**（[Spec-open.md](Spec-open.md) `O-a8`。fk-system `FK-X6`）。**決まるまでは共通の規則（[Spec-modes.md](Spec-modes.md) `SM-3.1.1-01`。人が手動 UI に触れたら一時停止）がそのまま効く。**S-60 には手動 UI を置かない（§6 の 3 つだけ） |
| 発進前に周りを確かめる仕組み | **未定**（[Spec-open.md](Spec-open.md) `O-a8`。fk-system `FK-X6`）。障害物リミッタ・経路の検査（§4.2）は常に効く |
