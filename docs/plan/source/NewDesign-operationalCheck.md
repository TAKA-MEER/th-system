# 動作確認システム詳細

動作確認したい部分を選択するとモニターが表示され動作を確認できる。

実装方式（画面構成・トピック設計など）はまだ検討しない。ここでは「理想的にはどう振る舞ってほしいか」だけを書く。

## 対象

| # | 項目                         | 何を確認するか                                                              |
| - | ---------------------------- | --------------------------------------------------------------------------- |
| 1 | 物理緊急停止ボタン           | 緊急停止ボタンの状態をシステムが把握しているか                              |
| 2 | モーター・エンコーダ動作確認 | 低速で指令通りに動くこと、エンコーダが回転を検出できること                  |
| 3 | IMU動作確認                  | BNO055のデータが届くこと、較正状態                                          |
| 4 | LiDAR動作確認                | `/scan` が正しい範囲・周期で届くこと、死角マスクが実機と合っていること 　 |

## 理想的な機能（4項目共通）

現状は各項目を確認する統一の手段がなく、トピックをターミナルで覗いたり `rviz2` を立ち上げたりと、確認する人によって手順が揺れる。理想はこれを一つの画面に集約する。

* **選ぶだけで見える**: 項目を選択した瞬間に、その場でモニターが立ち上がる。別ツールの起動やトピック名の暗記を要らなくする
* **合否をできる範囲で自動判定する**: 「データが届いているか」「値が想定範囲内か」は自動でOK/NGを示す。目視でしか判断できないもの（実際に機体が動いたか）は、どこを見ればいいかを画面が指し示す
* **総合ステータス**: 3項目すべての結果を一覧に集約し、「このまま使い始めてよいか」を一目で判断できる。個別に確認して回る必要をなくす
* **すぐ再実行できる**: 一度確認して終わりではなく、気になったときにいつでも同じ確認をやり直せる
* **異常時は[キャリブレーション](NewDesign-calib.md)へ誘導する**: ズレを検知したら、直すための画面（該当する較正項目）へその場で遷移できる。「気づく」動作確認と「直す」較正が別々に探し直す必要がないようにする
* **走行を伴う確認の安全設計**: ボタンを押している間だけ動き、離せば止まる。E-Stop・フォルトは即座に反映される。`IDLE`/`MANUAL` 以外では確認自体を始められない

## 1. 緊急停止ボタン

流れ: ボタンの状態と画面の表示が一致していることを確認。

## 2. モーター・エンコーダ動作確認

流れ: 前進・後退・右超信地旋回・左超信地旋回の4方向ボタンを押している間だけ低速で動く → 目視で機体が動くことを確認しつつ、画面側は指令と実測（エンコーダ）の追従をリアルタイムに見せる → ボタンを離すと自動で停止。

指令と実測の符号・追従が合っているかを自動でOK/NG表示し、目視確認と数値確認の両方を同時に行えるようにする。

## 3. IMU動作確認

流れ: 画面を開くと `/esp32/imu_data` の生死とジャイロ値がすぐに表示される → 静止状態でバイアスが小さいことを自動確認 → 較正状態（sys/gyro/accel/mag）をリアルタイムに表示し、未較正・劣化していれば「較正してください」と[キャリブレーション](NewDesign-calib.md)の該当項目へ誘導する。

較正済みで今は正常」なのか「劣化していて較正が必要」なのかを画面が判断し、後者のときだけ人に較正を促す（毎回同じ確認・同じ案内をなぞらせない）。

## 4. LiDAR動作確認

流れ: 画面を開くと生のスキャンがその場にライブ表示される → 死活・全周の有効性を自動確認 → 死角マスクを重ねて表示し、実機のアルミパイプの位置とズレていないかを目視で確認する。

角マスクのズレを自動検知できたら「較正してください」と[キャリブレーション](NewDesign-calib.md)の死角較正へ直接誘導する。既知距離の障害物との比較も、画面上でカーソルを合わせるだけで数値が読み取れるようにする。
