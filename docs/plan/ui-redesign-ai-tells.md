# WebUI の作り直し — AI っぽさ（目標 G2）

起票 2026-11-21。[ui-redesign.md](ui-redesign.md) の詳細。**未確定の検討メモ**であり [spec/](spec/README.md) を上書きしない。
元の調査は [ui-redesign-ai-research.md](ui-redesign-ai-research.md)（ユーザーが Opus 5.5 max で作成。出典つき）。

## 1. 基準

調査の結論をこのプロジェクトの基準として採る案。

* **画面の色・動き・装飾は、機体の状態か操作の意味に対応させる。**対応しないものは「誰も決めていない初期値の残り」とみなして外す。
* **理由を一文で言えない選択は直す**（調査の「一文テスト」）。
* 操作画面では、AI っぽさを消す作業は「状態・安全・操作を一目で正しく伝える」作業とほぼ同じ。G1（読まずに分かる）と同じ方向を向く。
* Web 向けの「大胆で記憶に残るデザイン」の勧めは採らない（産業 HMI の ISA-101 と逆向き）。
