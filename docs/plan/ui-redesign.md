# WebUI の作り直し — 検討メモ

起票 2026-11-12。**未確定の検討メモ**であり [spec/](spec/README.md) を上書きしない。
結論が出たら CLAUDE.md「方針変更時のルール」に従い、先に Spec-webui.md とモックアップを直してから実装する。

## 結論（たたき台）

* **ユーザーの評価（2026-11-12）**: 1 画面の情報量が多く使いにくい。ボタンが多くタブに分かれていて、目的のボタンがどこにあるか分からない。
* **細かい手直しではなく、画面の組み立てから変える。**全画面に「1 画面 1 目的」「状態で意味の無い操作は隠す」「平常のときは何も出さない」の規則を入れる（[options §1](ui-redesign-options.md)）。
* **メインメニューは 2 段の階層にし、大きなアイコンのタイルにする。**一番上は 5〜6 枚（いま 14 ボタン）。運用の終了と接続確認は一番上に残す（[options §2](ui-redesign-options.md)）。
* **試験場内はタブを無くし、状態ごとに出すものを入れ替える。**S-21 の待機中は 16〜17 → 約 5〜10、一時停止中は 17〜18 → 4（[options §3](ui-redesign-options.md)）。
* 作り直しを待たずに直せる不具合（英語の状態名など）は先に直す（[options §4](ui-redesign-options.md)）。

## 決めてほしいこと

1. **全画面の規則 R1〜R6**（[options §1](ui-redesign-options.md)）をこの方向で進めてよいか。特に R2（状態で意味の無いボタンは隠す。いまは薄く出す）と R4（いまの状態はボタンの色でなく文字で出す。U-17 を改める）
2. メインメニューは **M1 か M2 か**
3. S-21 は **F1 か F2 か**（F2 は地図の見やすさの検討と合わせて決める）
4. 案の画面をどこで見て決めるか（下の「次にやること」2）
