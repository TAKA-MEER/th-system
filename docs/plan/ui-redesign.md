# WebUI の作り直し — 検討メモ

起票 2026-11-12。**未確定の検討メモ**であり [spec/](spec/README.md) を上書きしない。
結論が出たら CLAUDE.md「方針変更時のルール」に従い、先に Spec-webui.md とモックアップを直してから実装する。

## 結論

* **ユーザーの評価（2026-11-12）**: 1 画面の情報量が多く使いにくい。ボタンが多くタブに分かれていて、目的のボタンがどこにあるか分からない。
* **細かい手直しではなく、画面の組み立てから変える。**ボタンは「まとめる・重複を消す」で減らし、**状態による入れ替えでは減らさない**（[options §1](ui-redesign-options.md)）。
* **配置は状態で変えない**（2026-11-13 ユーザー決定）。状態の変化で同じ場所のボタンの意味が変わると誤操作を招く。似た配置で中身が違う、を作らない。使えないボタンは場所を保ったまま薄く表示する。
* **対の操作（停止／走行など）はトグルの見た目にして関係を示す**（2026-11-13 ユーザー決定）。
* **メインメニューは M2**: 試験場 ▸・走行 ▸・点検と校正 ▸・自律測定・設定の大きなアイコンタイル（いま 14 ボタン → 一番上は 5）。運用の終了と接続確認は一番上に残す（[options §2](ui-redesign-options.md)）。
* **試験（当日）は F2**: タブを無くし、地図のピンを押して行き先を決める。右列のボタンは**どの状態でも同じ 9 個・同じ位置**（[options §3.1](ui-redesign-options.md)）。
* **試験準備**: 先に登録の方式を選び、次に待機場所か配電盤かを選ぶ（登録 6 ボタン → 方式 3＋登録先 2）。予約の停止・走行は残す（追従走行を足すときに組み直さないため）（[options §3.2](ui-redesign-options.md)）。
* 作り直しを待たずに直せる不具合（英語の状態名など）は先に直す（[options §4](ui-redesign-options.md)）。
