### 1.1 R2 の細目（案）

* **(a) 同じ場所に、状態によって別の操作を出さない。**その場所のボタンは状態によらず同じ操作で、変わるのは押せるか押せないかだけ。
* **(b) 似た配置で中身が違う、を作らない。**画面どうし・階層どうしでも、同じ位置・同じ形のボタンが違う意味を持たないようにする。
* **(c) 状態で使えないボタンは、場所を保ったまま薄く表示する。**隠してよいのは、隠しても他のボタンが動かず、その場所に別のものが出ないときだけ。隠すかどうかは個別に決める。

**R2 に照らして見直すもの**:
* S-20 の右上の「次にやること」ボタン（いまは同じ場所で「地図作成開始」「対象を選ぶ」「待機場所を登録」…と語が変わる）。**(a) に反する**。無くすか、語を固定する。
* 「中断」（いまは一時停止と `BLOCKED` のときだけ現れる）。場所を固定して、それ以外は薄く表示する。
* メインメニューの階層（§2.3）。

### 1.2 R4 のトグルにする対（候補）

## 2. メインメニュー（S-01）の多階層化 — **M2（種類の順）に決定**（2026-11-13）

**前提**: 下の階層も **S-01 の中**に置く（モードは `IDLE`・場外・速度上限は停止のまま）。新しい画面 ID は作らない。
階層は **2 段まで**。下の階層の左上に「戻る」（一番上へ）。走行方式を抜けたら、入った階層へ戻す（例: 手動走行を「終了」→「走行」の階層）。

### 2.1 一番上の階層

| 大タイル | 下の階層 |
| --- | --- |
| **試験場 ▸** | 試験準備 ／ 試験（当日） |
| **走行 ▸** | 追従走行 ／ 手動走行 ／ 教示（追従） ／ 教示（手動） ／ 教示再生 ／ ライン誘導 ／ 電子リード |
| **点検と校正 ▸** | 始業点検 ／ 校正 |
| 自律測定 | （下の階層なし。押すと W-4「自律動作を許可しますか」。spec は 2026-11-01 に追加、実装はまだ） |
| 設定 | （S-50 へ） |

**一番上に残すもの**: 接続確認の要約（緑・黄・赤の点と 1 行）・バッテリー・**運用の終了（未保存の件数と「制御系を停止する」）**。
運用の終了は F-23 の唯一の機会なので、下の階層へ入れない。
試験（当日）は 2 回押すことになる（M1 なら 1 回）。M2 は機能が増えても形が崩れないほうを採った。

### 2.2 タイルの形

* アイコン（インライン SVG）＋ 語 ＋（押せないときだけ）理由 1 行。横長で 3 列、縦長で 2 列。
* **下の階層のボタンがすべて押せないときは、一番上のタイルにもそれを出す**（例: 人検出が止まっていて追従系が全部押せない →「走行」のタイルに「追従は人検出が止まっています」）。入ってから気づかせない。
* アイコンの候補（たたき台）: 試験場＝地図とピン ／ 走行＝ハンドル ／ 点検と校正＝チェックリストとスパナ ／ 自律測定＝計測器 ／ 設定＝歯車 ／ 試験準備＝地図とペン ／ 試験（当日）＝旗 ／ 追従＝人と矢印 ／ 手動＝スティック ／ 教示＝丸と軌跡 ／ 再生＝三角と軌跡 ／ ライン＝線 ／ 電子リード＝ひも。

### 2.3 R2 (b) との関係

一番上と下の階層はどちらもタイルの並びなので、「似た配置で中身が違う」に当たりうる。次で見分けを付ける（案の画面で確かめる）。

* 下の階層は、上端に**いまの階層の名前とアイコン**（「走行 ▸」）を大きく出す
* 「戻る」の位置は全階層で固定（左上の操作バー。§4.1 の「終了」と同じ場所）
* 区画ごとに色の帯を変える（試験場・走行・点検と校正）

* **消すもの**: ピンの行ごとの「移動」×N（地図のピンで選ぶ）・3 か所の「会場地図を開く」・「地図の更新 OFF」（使えるようになるまで出さない。R2 (c) で隠してよい条件を満たす）・「人検出を停止」の常時表示。
* **呼び寄せ**: 押すと主表示に対象のレーダーを重ねて 2 点指示へ。**対象が見えないまま実行させない**（§4.1 の安全要件）。

* **前提**: 地図が読めること・タブレットでピンが押せる大きさであること（[venue-map-readability.md](venue-map-readability.md)）。ピンの一覧が要るなら、地図の上に小さく重ねる。
