# 保管場所から試験場への移動

複数の走行方法をPoCとして開発し、試験、選定する。

## 追従走行

LiDARで足を検知しその位置の軌跡を追従する。

### 追従走行 使用方法

1. 追従走行を選択
2. 追従走行画面に移る
3. 追従対象を選択
4. "確認"を押すと機体が追従対象の方を向く(移動はしない)
5. 試験員が左右に動き、向きが追従されることを確認する
6. 追従開始を押す
7. ゆっくり目的地まで歩く
8. 試験員が歩いた場所をなぞるように機体も移動する(試験員が直角に曲がった場合などにショートカットしない)
9. 機体は試験員が近くにいる場合は止まる。
10. 到着したら追従走行を停止させる。
11. 追従走行を終了させる。

### 追従走行　教示

"教示　追従走行"選択後、既存経路の再設定もしくは新規経路の設定を選択、直後から記録を開始する。

"確認"の動きは省略し走行開始時の向きを記録、再生時は最初その角度まで超信地旋回する。

一時停止は省略し再生時はズムーズに走行させる。

## 手動走行

基本的に現行のまま。

他の走行方式操作画面でも同様の手動操作をできるようにする(UIも配置する)。

LiDARが障害物を検知した場合は警告する。自動ブレーキ機能も搭載する。(デフォルトではオフ)

教示において一時停止は省略し再生時はズムーズに走行させる。

### 手動走行　使用方法

1. 手動走行を選択
2. 手動走行画面に移る
3. 手動走行する
4. 到着したら終了させる。

## 教示再生走行

教示で記録した地図と経路のデータを用いて教示時の経路を辿る。

### 教示

走行方式選択画面で教示をするかを決める。途中から教示はしないため。

教示データはdockerワークスペースに保存される。エクスポート、インポートも可能。

教示モードではLiDARで地図を作りつつ,IMU,エンコーダで経路を作成する。

### 教示再生走行　使用方法

1. 教示再生を選択
2. 教示再生走行画面に移る
3. 経路(内部的には地図と逆再生かどうか)を指定(初期位置の設定)。逆再生も選択肢に含める。角度の指定は不要
4. 正確な初期姿勢をLiDARで推定。確度が低い場合は範囲を広げ場合によっては完全グローバルローカライゼーションを行う。
5. 経路途中からの復帰用に最初から完全グローバルローカライゼーションさせることも可能
6. 初期姿勢の推定が正確であることを表示される地図と位置をみて確認。
7. "再生"を押し走行を開始させる。
8. LiDARが障害物を検知した場合は停止する。自動回避はせず、人が手動操作するか障害物をどける
9. 到着したら停止する。
10. 教示再生走行を終了する。

地図の更新をいつでもオンオフできるようにする。

## 区画線走行

カメラで区画線、区画線分岐を認識し走行する。LiDARは障害物検知にのみ

### 事前準備

工場内の全ライン経路を「ノード(分岐点)」と「エッジ(ライン区間)」からなるマップとして登録する。

1. 区画線走行を選択
2. マップ編集を選択
3. [以降設計はあとにまわす]

### 区画線走行　使用方法

1. 区画線走行を選択
2. 区画線走行画面に移る
3. 機体を区画線を認識する位置に配置
4. マップから現在地を選択(マップ上をクリック)
5. マップで向き方向の位置を選択(方向ベクトルがわかる)
6. マップから目的地を選択
7. 自動で経路を計算しマップに反映される
8. 走行開始を押す
9. 区画線走行が開始される
10. 目的地につくと自動で停止する
11. 区画線走行を終了させる。

## 電子リード走行

試験員がリード（紐・ケーブル状のもの）を持って歩き、リードを引っ張ると進みリードに張力がかからなくなると止まる。引っ張られること引っ張られる向きで操る。進む速度は一定(ゆっくり加減速する処理は当然入れる)。

### リードデバイス

RaspberryPi4にUSBで接続するArduinoのデバイス

リードに張力がかかっていること、リードの向きを得られる。

### 電子リード走行　使用方法

1. 電子リード走行を選択
2. 自動でリードデバイス接続確認
3. 走行開始を押す
4. リードを引き目的地まで歩く
5. 到着したら停止を押す
6. 電子リード走行を終了する
