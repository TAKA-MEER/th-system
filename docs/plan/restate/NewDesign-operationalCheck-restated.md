## 0. この機能の位置づけ

**「気づく」ための機能である。「直す」のは[キャリブレーション](NewDesign-calib-restated.md)。**

```
動作確認（気づく） ──ズレを検知──> キャリブレーション（直す） ──> 動作確認（直ったか見る）
```

原文が繰り返し言っているのはこの一点で、**両者が別画面で行き止まりにならないこと**を求めている。

実装方式（画面構成・トピック設計）はまだ決めない。**理想的にはどう振る舞ってほしいか**だけを書く。

## 4. 項目ごとの流れ

### 1. 緊急停止ボタン

ボタンの状態と画面の表示が**一致していること**を確認する。それだけ。

### 2. モーター・エンコーダ

|              | 内容                                                            |
| ------------ | --------------------------------------------------------------- |
| 操作         | **前進・後退・右超信地旋回・左超信地旋回**の 4 方向ボタン |
| 動く条件     | **押している間だけ低速で動く。離すと自動停止**            |
| 画面         | 左右輪それぞれの**指令値と実測値をリアルタイム表示**      |
| 自動判定     | 指令と実測の**符号・追従**が合っているか                  |
| 人がやること | **機体が実際に動いたことを目視**                          |

**目視確認と数値確認を同時にやれる**ことが狙い。

### 3. IMU

|              | 内容                                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| 画面を開くと | `/esp32/imu_data` の**生死とジャイロ値**がすぐ出る                                             |
| 自動判定     | **静止状態でバイアスが小さいこと**                                                               |
| 常時表示     | 較正状態**sys / gyro / accel / mag** をリアルタイムに                                            |
| 分岐         | **「較正済みで今は正常」か「劣化していて較正が必要」かを画面が判断し、後者のときだけ較正を促す** |

**毎回同じ確認・同じ案内をなぞらせない**ことが狙い。

### 4. LiDAR

|                  | 内容                                                                         |
| ---------------- | ---------------------------------------------------------------------------- |
| 画面を開くと     | **生のスキャンがその場でライブ表示**される                             |
| 自動判定         | 死活、**全周の有効性**                                                 |
| 重ね表示         | **死角マスクを重ねて**、実機のアルミパイプの位置とズレていないかを目視 |
| 自動検知できたら | **死角較正へ直接誘導**                                                 |
| 補助             | **既知距離の障害物との比較を、カーソルを合わせるだけで数値で読める**   |

## 6. 画面の構成（原文の ASCII 図を文章に開いたもの）

### 一覧画面

* 4 項目を縦に並べ、それぞれに状態の印（✓ / ! など）を付ける。
* 右上に**総合ステータス**（例:「要確認 1 件」）。
* 項目を選ぶと右側に詳細が出て、「開始」ボタンで確認を始める。

### モーター・エンコーダ確認画面

* 上段に 4 方向のホールドボタン。**押している間だけ強調表示**になる。
* 中段に左右輪の**指令値・実測値・判定**を並べる。
* 「ボタンを離すと停止」を画面に明示する。

### IMU 確認画面

* **データ受信からの経過時間**と**静止時 vyaw** をそれぞれ判定付きで表示。
* 較正状態 4 種を**バー（n/3）**で表示し、**劣化しているものを指し示す**。
* 「キャリブレーションへ」ボタン。

### LiDAR 確認画面

* 受信周期・全周有効値をそれぞれ判定付きで表示。
* **ライブスキャンの上に死角マスク（登録値）を重ねて描く**。実際の写り込みとズレていれば見て分かる。
* **カーソル位置の角度と距離**を数値で出す。
* ズレを検知したら「キャリブレーションへ」ボタン。
