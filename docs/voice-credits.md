# 音声クレジットと利用条件

TH システムの音声アナウンス（[docs/voice-and-audience.md §2](voice-and-audience.md#2-音声フィードバック)）で使用している
音声素材のクレジットと、遵守すべき条件をまとめる。

---

## クレジット表記

> **VOICEVOX Nemo**

この表記が必要な箇所は以下のとおり。**いずれか一つではなく、すべてに置く。**

| 場所 | 状態 | 備考 |
| --- | --- | --- |
| リポジトリの [README.md](../README.md) | ✅ 記載済 | リポジトリを見た人に届く |
| タブレット WebUI の音声通知カード | ✅ 記載済 | 実行時に画面上で見える |
| 発表資料・デモ動画 | ⬜ 発表時に対応 | 口頭のみでなく画面にも出す |

---

## なぜ Nemo を選んだか

TH システムにはオリジナルキャラクター構想があり、その声として音声素材を使う。

通常の VOICEVOX キャラクター（ずんだもん・四国めたん等）は**キャラクターごとに個別の
利用規約**があり、「そのキャラクターとして扱う」ことが前提になっている。オリジナル
キャラクターの声として使うと、キャラクターの同一性に関わる部分で規約と衝突しうる。

**VOICEVOX Nemo はキャラクターとしての人格を持たない読み上げ専用の音声ライブラリ**で、
この衝突が最初から存在しない。加えて、

- クレジット「VOICEVOX Nemo」の表記のみで**商用・非商用を問わず利用できる**
  （キャラクターごとの個別規約を確認する必要がない）
- 認知度の高いキャラクター音声と違い、聞いた瞬間に既存キャラと判別されない

という点が、企業向け提案・発表という用途に合っている。

## 遵守事項

利用規約（<https://voicevox.hiroshiba.jp/nemo/term/>）の禁止事項のうち、
本プロジェクトで特に注意が要るもの。

- **クレジット表記なしでの利用** — 上表の 3 箇所を必ず維持する
- **著作情報の偽造** — 「完全自作の音声」として提示しない。オリジナルキャラクターの
  声ではあるが、音声合成は VOICEVOX Nemo によるものである旨を明示する
- **機械学習での利用** — 生成した音声を学習データに使わない
- **VOICEVOX・音声提供者の信用、品質、品位、イメージを著しく損なう利用**

### リポジトリが公開設定である点

このリポジトリは公開設定のため、生成した音声ファイルをコミットすると公開配布になる。
規約上、生成した音声はクレジット表記があれば利用できるため配布自体は問題ないが、
**クレジットがリポジトリ内に存在することが前提**になる。README.md の記載を消さないこと。

## 生成環境

**Nemo は VOICEVOX 本体とは別のエンジンで、VOICEVOX アプリに VVPP プラグインとして
追加して使う。** `voicevox/voicevox_engine` の Docker イメージには**含まれていない**
（あちらはキャラクター版 43 名で、Nemo の 9 話者は入っていない）。

導入は VOICEVOX アプリの「エンジンの管理」から。公式サイトの案内に従って
VOICEVOX Nemo Engine の vvpp を追加すると、次の場所に展開される。

```txt
%APPDATA%\voicevox\vvpp-engines\VOICEVOX_Nemo_Engine+<uuid>\
```

生成時はエンジンを起動しておく。VOICEVOX アプリを立ち上げれば自動で起動するが、
GUI なしで動かすこともできる。

```powershell
# 既定ポートは 50121 (VOICEVOX 本体の 50021 とは別)
cd "$env:APPDATA\voicevox\vvpp-engines\VOICEVOX_Nemo_Engine+<uuid>"
.\run.exe --port 50121
```

生成スクリプトの既定接続先が 50121 なのはこのため。50021 は VOICEVOX 本体
（キャラクター版）なので、そちらに繋ぐと Nemo の話者が見つからない。
