# 音声クレジットと利用条件

TH システムの音声アナウンス（[VISION.md §7](../VISION.md#7-音声フィードバック)）で使用している
音声素材のクレジットと、遵守すべき条件をまとめる。

---

## クレジット表記

話者は通常運用の **VOICEVOX Nemo**（既定）と、展示専用の例外として追加した
**ずんだもん**（下記「展示専用の例外」参照）の2種類あり、**表記はどちらを使っているかで
異なる**。誤ったクレジットを出したままにすると規約違反になるため、いずれか片方だけでなく
選択中の話者に対応するものを出す。

| 話者 | クレジット表記 |
| --- | --- |
| Nemo（既定） | **VOICEVOX Nemo** |
| ずんだもん（展示専用） | **VOICEVOX:ずんだもん**（コロン、スペース無し。ずんだもんの規約が定める表記） |

表記が必要な箇所は以下のとおり。**いずれか一つではなく、すべてに置く。**

| 場所 | 状態 | 備考 |
| --- | --- | --- |
| リポジトリの [README.md](../README.md) | ✅ 記載済 | リポジトリを見た人に届く。両話者を配布するため両方を記載 |
| タブレット WebUI の音声通知カード | ✅ 記載済 | 選択中の話者に応じて動的に出し分ける（`App.jsx` の `CREDIT_TEXT`） |
| 発表資料・デモ動画 | ⬜ 発表時に対応 | 口頭のみでなく画面にも出す。使用した話者の表記を選ぶこと |

---

## なぜ Nemo を選んだか

TH システムにはオリジナルキャラクター構想があり、その声として音声素材を使う。

通常の VOICEVOX キャラクター（ずんだもん・四国めたん等）は**キャラクターごとに個別の
利用規約**があり、「そのキャラクターとして扱う」ことが前提になっている。オリジナル
キャラクターの声として使うと、キャラクターの同一性に関わる部分で規約と衝突しうる。

**VOICEVOX Nemo はキャラクターとしての人格を持たない読み上げ専用の音声ライブラリ**で、
この衝突が最初から存在しない。加えて、

- クレジット「VOICEVOX Nemo」の表記のみで**商用・非商用を問わず利用できる**
  （キャラクターごとの個別規約を確認する必要がない）
- 認知度の高いキャラクター音声と違い、聞いた瞬間に既存キャラと判別されない

という点が、企業向け提案・発表という用途に合っている。

**通常運用の既定は今後も Nemo のまま変えない。** 次項の「展示専用の例外」はこの方針を
覆すものではなく、用途を限定した追加の選択肢である。

---

## 展示専用の例外: ずんだもん（2026-08-07 決定）

展示会場でのデモでは、認知度の高いキャラクター音声の方が観客の反応を得やすい。上記の
「Nemo を選んだ理由」（＝キャラクター個別規約とオリジナルキャラクター構想の衝突を避ける
ため）は、**音声をオリジナルキャラクターの声として使う場合にのみ当てはまる**問題である。
展示デモで **ずんだもんをずんだもん自身として（正しくクレジットして）使う**分には、
この衝突はそもそも発生しない。

- **対象は展示専用**。通常運用（オリジナルキャラクター構想の文脈）では引き続き Nemo を
  使う。WebUI フッターの話者切替ボタンで手動選択する方式とし、既定値は Nemo のまま
  （`th_voice_speaker` の既定値。§7.5 参照）
- **話者はずんだもん「ノーマル」**（VOICEVOX 本体・通常版 Engine、style id 3）
- **クレジットは `VOICEVOX:ずんだもん`**（コロン、スペース無し）。ずんだもん選択中は
  WebUI フッターのクレジット表記もこちらに切り替わる
- **利用規約**（<https://zunko.jp/con_ongen_kiyaku.html>）の要点:
  - 商用・非商用とも、クレジット表記があれば無償で利用可能（クレジット省略時のみ
    1キャラ40万円(税別)の有償契約が必要 — 本プロジェクトは常にクレジット表記するため
    非該当）
  - 禁止事項: 公序良俗に反する利用／政治・宗教活動や特定団体への非難・応援目的の
    利用／情報商材での利用／意図的な虚偽・フェイク情報の作成・拡散／風俗営業関連
    業態での利用／反社会的勢力による利用
  - 著作情報の偽造禁止（Nemo と同様）: 音声合成が VOICEVOX（ずんだもん）によるもので
    ある旨を隠さない

---

## 遵守事項（Nemo）

利用規約（<https://voicevox.hiroshiba.jp/nemo/term/>）の禁止事項のうち、
本プロジェクトで特に注意が要るもの。ずんだもんの遵守事項は上記「展示専用の例外」に
別掲している。

- **クレジット表記なしでの利用** — 上表の 3 箇所を必ず維持する
- **著作情報の偽造** — 「完全自作の音声」として提示しない。オリジナルキャラクターの
  声ではあるが、音声合成は VOICEVOX Nemo によるものである旨を明示する
- **機械学習での利用** — 生成した音声を学習データに使わない
- **VOICEVOX・音声提供者の信用、品質、品位、イメージを著しく損なう利用**

### リポジトリが公開設定である点

このリポジトリは公開設定のため、生成した音声ファイルをコミットすると公開配布になる。
規約上、生成した音声はクレジット表記があれば利用できるため配布自体は問題ないが、
**クレジットがリポジトリ内に存在することが前提**になる。README.md の記載を消さないこと。

## 生成環境

**Nemo は VOICEVOX 本体とは別のエンジンで、VOICEVOX アプリに VVPP プラグインとして
追加して使う。** `voicevox/voicevox_engine` の Docker イメージには**含まれていない**
（あちらはキャラクター版 43 名で、Nemo の 9 話者は入っていない）。**ずんだもんは逆に
この通常版 Engine（キャラクター版）側に含まれている**ため、Nemo とは別プロセス・別
ポートで起動する必要がある。

| 話者 | Engine | 既定ポート | `generate_voice.py --profile` |
| --- | --- | --- | --- |
| Nemo | VOICEVOX Nemo Engine（VVPP プラグイン） | 50121 | `nemo`（既定） |
| ずんだもん | VOICEVOX 本体（通常版 Engine） | 50021 | `zundamon` |

Nemo の導入は VOICEVOX アプリの「エンジンの管理」から。公式サイトの案内に従って
VOICEVOX Nemo Engine の vvpp を追加すると、次の場所に展開される。

```txt
%APPDATA%\voicevox\vvpp-engines\VOICEVOX_Nemo_Engine+<uuid>\
```

生成時は両方またはどちらか一方のエンジンを起動しておく。VOICEVOX アプリを立ち上げれば
自動で起動するが、GUI なしで動かすこともできる。

```powershell
# Nemo (既定ポート 50121。VOICEVOX 本体の 50021 とは別)
cd "$env:APPDATA\voicevox\vvpp-engines\VOICEVOX_Nemo_Engine+<uuid>"
.\run.exe --port 50121

# 通常版 (ずんだもん用。VOICEVOX アプリを普通に起動すれば既定ポート 50021 で立ち上がる)
```

`--profile nemo`（既定）は 50121、`--profile zundamon` は 50021 へ自動的に接続する。
50021 に Nemo の話者id を、あるいは 50121 にずんだもんの話者idを渡すと見つからずエラーに
なる（エンジンを取り違えていないか確認すること）。

```bash
python th_ws/scripts/generate_voice.py --profile nemo
python th_ws/scripts/generate_voice.py --profile zundamon
```
