1. 目的

製品は、実証実験の当日、試験場内にある複数の配電盤の前へ順に移動し、その都度カメラを 昇降させて盤の上部を確認する。この「配電盤の前まで正確に移動する」動作 （以下、試験場内動作）が実現できるか、また実用に足るかを検証する。

試験場内動作は前日と当日の2段階からなる。前日、ロボットに試験会場内を 一通り案内しながら周囲の地図を作り、各配電盤の位置を1つずつロボットに教える （登録）。当日は、登録しておいた位置を選ぶだけで、 ロボットが単独でその盤の前まで移動し、向きを合わせて停止する。

本資料は、2026年9月14日にクリエイティブラボで実施した2回の試験の結果をまとめたものである。

  • 第1回：5つのブースを配電盤5箇所に見立て、前日準備から当日の全箇所 巡回・障害物や人への対応・待機場所への呼び寄せまで、一連の流れが事故なく動作するかを 確認した。
  • 第2回：配電盤の位置をロボットに教える方法（登録方式）を3通り用意し、 どれが最も実用的かを比較した。

登録方式は次の3通りである。

方式やり方
いまの姿勢で登録ロボット本体を実際に配電盤の前まで動かし、そこで「ここに登録」を押す。ロボット自身がそのとき認識している位置がそのまま記録される。
2点指示試験員が配電盤の前に立ってボタンを押し、続けて盤へ一歩近づいてもう一度押す。ロボットは周囲の人を検知するセンサでこの2点を読み取り、位置と向きを計算する（ロボット自体は動かさなくてよい）。
地図タップ（今回新規に実装）タブレット画面に表示された地図を指でタップして位置を、そこからもう一点ドラッグして向きを指定する。ロボットも人も動かさず、画面の操作だけで完結する。

2. 検証対象KPI（合格基準）

第1回は一連の動作が実際に成立するか（実現可能性）を、第2回は 3つの登録方式のどれが実用的かを検証する。

#合格基準
K1前日準備（地図作成→全盤登録→待機場所への復帰→保存）が一連で完了する
K2当日、登録した全ての盤を事故なく巡回できる
K3移動中に人や障害物が現れても、衝突せず自動で停止・再開する
K4呼び寄せ（試験員のいる位置へ移動）と、対象の選び直しが機能する
K53つの登録方式とも、登録した位置へ実際に到達できる

配電盤の前で行うカメラ昇降作業がどれだけの位置ずれを許容できるかは、カメラ昇降機構側の 検討が今後さらに進んでから判明する性質のもので、現時点では数値の合格基準を定められない。 そのため位置決めの精度そのものには絶対的な合格ラインを設けず、3方式の相対比較 と、登録にかかる時間・作業の負担を評価軸とする。これは先方から前日準備の 負担を減らしたいという要望があるためでもある。

3. 検証方法

会場クリエイティブラボ。第1回はブース5箇所を配電盤に見立てた。第2回は会場の都合で1箇所のみ
実施2026年9月14日

第2回は、同じ1地点に3方式とも順番に登録し、それぞれの登録した座標を比較した。 位置決めの「正解」は、ロボット本体をその地点へ実際に置き、そのときロボットが 認識している自己位置を読み取ることで求めた。メジャーや分度器で壁や柱から 測ろうとすると、地図上のどこを基準にすればよいか分かりにくく実施が難しかったため、 ロボット自身の自己位置をそのまま「正解」として使う方法に切り替えた。

4. 結果まとめ

第1回：試験場内動作の一連の流れは、今回の会場条件では事故なく動作した。

#判定根拠（実測結果）
K1合格前日準備一連を3分55秒で完了（地図作成→5箇所登録→待機場所復帰→保存）
K2合格当日、5箇所すべてに到達。途中で止まることなく5分11秒で全箇所を巡回
K3合格人の飛び出し・障害物の設置・連続した進路ふさぎ、いずれも自動で停止し、障害物が無くなれば自動で再開した
K4合格呼び寄せ・対象の選び直しとも正常に動作

第2回：3方式とも登録した位置へ実際に到達できた（K5合格）。 位置決めの精度は「いまの姿勢で登録」が今回最も正確だったが、会場の都合で検証が1地点・ 各方式1〜2回にとどまり、まだ確定的な傾向とは言えない。作業の負担という観点では、 「地図タップ」がロボット・試験員のどちらも動かす必要がなく、前日準備の負担軽減という 先方要望に最も応えられる可能性がある。ただし地図タップは今回新規に実装したばかりで、 実機での使用実績はまだ浅い。詳しい比較は5節で述べる。

5. 登録方式の比較（第2回）

参考として、登録した位置へロボットが自動で移動したときの最終的な停止位置の ずれも測った（3方式×3回、平均値）。いまの姿勢で登録12.0cm、2点指示28.7cm、地図タップ 27.0cmで、登録方式による差より大きな値になった。差の大部分は、自動移動の仕組み そのものが目的地への到達を「これくらいまでのずれなら良し」とみなす許容範囲に由来しており、 登録方式を問わずすべての方式に共通して乗ってくる。つまり、位置決め精度を上げる うえでは、登録方式そのものの改善よりも、自動移動の到達精度を改善するほうが3方式すべてに 一律に効くと考えられる。

「いまの姿勢で登録」の110秒には、ロボット本体を盤の前まで運ぶ移動時間が含まれるため、 単純な操作の速さの比較ではない。盤の数が多い会場では、ロボットを物理的に運ぶ 必要がある「いまの姿勢で登録」ほど前日準備の所要時間が延びると見られる一方、地図タップは ロボット・試験員のどちらも動かす必要がなく、タブレット画面の前にいるだけで全ての盤を 登録できる。この観点では地図タップが前日準備の負担軽減に有利と考えられるが、 今回新規実装したばかりで、実機投入の際にタブレットでの操作性に関する不具合が2件見つかり その場で修正しており、まだ十分にこなれていない。

6. 各回の詳細

6-1. 第1回（5箇所巡回・安全機能）

前日準備は、地図作成を開始し、5箇所を順に「いまの姿勢で登録」で登録、登録完了後に 1ボタンで待機場所へ戻り、保存する一連を3分55秒で完了した。当日は、会場地図を読み直して 「待機場所にいる」と宣言したのち、5箇所すべてに1回ずつ自動移動して到着し、最後に待機場所へ 自動で戻る一連を5分11秒で、途中で止まることなく完了した。

このうち1箇所（panel_2）は単独で往復して到着精度を実測し、到着時間40秒・位置のずれ7cm・ 向きのずれ4°だった。別の1箇所（panel_1）への移動中には、次の安全機能の確認をあわせて 実施した。

  • 進路に人が飛び出す → 自動で停止 → 人が退避 → 自動で再開
  • 進行方向に段ボール箱を置いて進路をふさぐ → 停止 → 撤去 → 自動で経路を引き直して再開 （停止から接触までの余裕は約30cm、再開までの動作は約1.5秒、手動での操作は不要だった）
  • 再開した直後にもう一度同じ場所をふさぐ（連続した進路ふさぎ） → 再度自動で停止

いずれも衝突なし。呼び寄せ（試験員のいる位置へロボットを呼ぶ機能）と、追跡対象の選び直しも 別途簡易確認し、正常に動作した。

今回未確認だったのは、ロボットが動いている最中に非常停止ボタンを押した場合の挙動（静止時の 確認のみ実施）、進路がふさがれたまま長時間動けない状態からの中断操作、配電盤に近すぎる 位置へ登録しようとしたときの警告表示の実際の発生、の3点である。

6-2. 第2回（登録方式の比較）

試験当日に「地図タップ」方式を新規に実装し、その日のうちに実機のタブレットで動作確認した。 確認の過程で、タブレットで地図を拡大する操作ができない不具合と、タップした位置と実際に 登録される位置がずれる不具合の2件が見つかり、いずれもその場で修正して再確認した。

まず3方式それぞれで、登録→ロボットが自動で目的地へ移動→停止位置を実測、を3回ずつ行った。 この時点では3方式とも最終的な停止位置のずれが大きく出たが、これは4節・5節で述べた通り、 自動移動の到達許容に起因する部分が大きいことが後から判明した。そこで測定方法を見直し、 ロボットを実際にその地点へ置いて自己位置を読み取ることで「正解」の座標を求め、 自動移動を介さずに登録方式そのものの精度を3方式まとめて比較した （結果は5節の表のとおり）。

7. 考察・今後の方針

試験場内動作の一連の流れ（前日準備・当日の巡回・障害物や人への対応・呼び寄せ）は、 今回の会場条件で事故なく動作することを確認できた。登録方式についても、3方式とも 実際に目的の位置へ到達できることを確認した。

一方で、登録方式の精度比較は会場の都合で1地点・少ない回数にとどまっており、まだ確定的な 傾向とは言えない。特に、配電盤の前が狭い場所や、試験員以外の人が近くにいる状況では、 方式ごとに得意・不得意が入れ替わる可能性がある（「いまの姿勢で登録」は狭い場所でロボット 本体を精密に動かすのが難しくなる、「2点指示」は人の混雑に弱くなる、といった具合）。 次回、そうした条件を用意したうえで再検証する。

位置決めの精度をどこまで詰める必要があるかは、配電盤前でのカメラ昇降作業がどれだけの ずれを許容できるかによって決まる。これがまだ確定していないため、今回は方式間の相対比較に とどめた。今後この許容差が明らかになった時点で、改めて実用可否を判定する。それまでの間、 自動移動の到達精度を改善する取り組みは、登録方式によらず3方式すべての最終的な精度を 一律に底上げできる点で優先度が高いと考えられる。

前日準備の負担軽減という観点では、ロボット・試験員のどちらも動かす必要がない「地図タップ」 が理論上最も有利と考えられる。ただし今回新規実装したばかりで実機での使用実績が浅いため、 今後複数回使ったうえでこなれ具合を含めて再評価したい。
