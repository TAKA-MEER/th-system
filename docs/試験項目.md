## 1. この試験のねらい

**先方立ち会いのもとで「試験場内で行う動作」（前日準備・当日の配電盤移動・呼び寄せ・安全機能）が
実現可能であることを見せるデモであり、同時に、フェーズ2の実装を実機で初めて通しで動かす
統合試験でもある。**

[VISION.md](../VISION.md) §2.5 フェーズ2 のスコープ（前日＝地図作成・ピン登録、当日＝宣言→
盤前移動・呼び寄せ→待機場所復帰）はコード上すべて配線済みだが、開発中の実機テストで
見つかったバグ（BLOCKED 膠着・幽霊コストマーク・中断導線の欠落・ピンの壁近接など）を
直した「はず」の状態のまま、**通しでの実機検証がまだ一度もできていない**。今回はデモと
同時にこれを確かめる最初の機会になる。

見るのは大きく3つ。

1. **前日準備が「大変」ではないこと**（地図作成・ピン登録が短時間で完了する）
2. **当日の一連動作が通しで動くこと**（宣言 → 盤前移動 → 作業 → 呼び寄せ → 復帰）★最大の関門
3. **安全機能が実機で実際に効くこと**（人の横断・障害物・非常停止）

## 2. 事前条件

- [ ] 会場の通路幅を事前に確認した（**幅 1.3m 未満の区間がないか**。実寸正方形 footprint の
      自動走行下限は理論上 約1.10m だが、設計上は **1.3m 以上を推奨**。[VISION.md](../VISION.md) §2.5）
- [ ] 配電盤の設置位置を確認し、**壁からの可動余地が 0.45m 以上**取れそうか目視で見積もった
      （取れない場合、ピン登録時に警告が出て「壁から離して登録」を選ぶ想定で臨む）
- [ ] `pi_serial_relay` が動いている
      ```bash
      ssh mirs2602@192.168.5.1 'systemctl is-active rpi-serial-relay'   # → active
      ```
- [ ] 床に**待機場所マーク**（ビニールテープ）を貼った。当日の地図読み直しは、機体が
      このマークの位置にいるものとして自己位置を合わせる（[使い方.md](使い方.md) §3-4b 手順1）
- [ ] `stage:=4` で起動した（人物トラッカー・Nav2・onsite ノードが要る。[使い方.md](使い方.md) §3-4b）
- [ ] 健全性確認 5項目に加え、**stage:=4 特有の「解除」1回**が要ることを立会者に事前説明した
      （[使い方.md](使い方.md) §2「`stage:=4`で起動したとき」。N-27。デモ冒頭で慌てないため）
- [ ] 障害物役（台車や箱など、すぐ退避できるもの）と、進路を横切る役の人を1名ずつ用意した
      （安全機能デモ用。**必ず自分から退避できる位置・速度で行い、機体の停止を確認してから
      距離を詰める。停止を確認する前に体を寄せない**）
- [ ] 走行中いつでも「停止」または物理非常停止ボタンを押せる人が付き添う
- [ ] バッテリーが十分（前日相当の準備 ＋ 当日の一連動作を通しで、複数回の移動を含めて走る）

## 3. デモ兼試験の流れ

3段構成。フェーズA・Bは通しで見せ、フェーズCは各動作の合間に差し込む。各ステップの
番号は下記「4. 試験項目」の T- 番号に対応する。手順そのものは書かない（[使い方.md](使い方.md) §3-4b が正）。

### フェーズA — 前日準備をダイジェストで実演（T-1〜T-4）

会場を軽く一周して地図を作り、待機場所と配電盤（2箇所以上）を登録して保存する。
**配電盤の1箇所はあえて壁に寄せて登録し、壁近接警告が出ることを見せる。**

### フェーズB — 当日動作を通しで実演（T-5〜T-11）★最大の関門

待機場所宣言 → 配電盤1へ自動移動・向き合わせ → 「作業中」→ 配電盤2への移動、または
その場で呼び寄せ（2点指示 → 退避待ち → 自動発進）→ 待機場所へ自動復帰、まで止めずに通す。

### フェーズC — 安全機能を実演（T-12〜T-13）

フェーズBの移動中に差し込む。

- 移動中の進路に人が横切る → 自動減速・停止を確認 → 離れたら自動再開
- 移動中の進路に障害物を置く → `BLOCKED` を確認 → どけて自動再開を確認
- 任意のタイミングで物理非常停止ボタンを押す → 停止・解除を確認

## 4. 試験項目

### T-1. 起動と健全性（`stage:=4`）

| | |
| --- | --- |
| やること | `stage:=4` で起動し、健全性確認 5項目を確認する |
| 見るもの | N-27（起動15〜60秒のESTOP）が出るか。「解除」1回で `IDLE` に戻るか |
| **合格** | 「解除」を**1回**押せば `IDLE` に戻る。以後、走行を始めるまでフォルトが再発しない |
| 記録 | N-27発生の有無: ____ ／ 「解除」を押した回数: ____ 回 ／ 他に出たフォルト種別: ____________ |

### T-2. 前日準備 — 会場地図の作成

| | |
| --- | --- |
| やること | 会場を一周（往復可）してジョグで地図を作る |
| 見るもの | 地図が伸びるか（伸びなければSLAM未反映）。所要時間 |
| **合格** | 配電盤・待機場所を登録する範囲がすべて地図に写る |
| 記録 | 所要時間: ____ 分 |

### T-3. 前日準備 — ピン登録（待機場所・配電盤 × 2箇所以上）

| | |
| --- | --- |
| やること | 待機場所を1箇所、配電盤を2箇所以上登録する（うち1箇所は壁に寄せて登録し警告を発生させる） |
| 見るもの | 2点指示・「いまの姿勢で登録」の両方式が成立するか。壁近接時に3択の警告が出るか |
| **合格** | 全ピンが登録され地図上に表示される。壁近接ケースで警告が出て「離して登録」で解決できる |
| 記録 | 登録に要した回数（`two_point_too_close`等の拒否回数）: ____ 回 ／ 警告が出たピン: ____________ |

### T-4. 前日準備 — 会場地図の保存と当日の読み直し

| | |
| --- | --- |
| やること | 「保存」→（起動し直すか同一セッションのまま）「保存した会場地図を開く」 |
| 見るもの | 「（注意: ピンの登録時と保存済み地図が一致していない可能性…）」の警告が出ないか |
| **合格** | 警告なしで地図・ピン・自機位置が一致した状態で開ける |
| 記録 | 警告の有無: ____ ／ 読み直しに要した時間: ____ 秒 |

### T-5. 当日 — 待機場所の宣言

| | |
| --- | --- |
| やること | 待機場所マークに機体を置き、「宣言する」を押す |
| 見るもの | 大きなズレ警告が出ないか（手順どおり配置していれば正常はズレなし） |
| **合格** | ズレ警告なしで「宣言済み」になる |
| 記録 | ズレ量が表示された場合の値: ____________ |

### T-6. 当日 — 配電盤への自動移動・到着精度 ★最大の関門①

| | |
| --- | --- |
| やること | 行き先タブで配電盤ピンを選び、自動移動させる |
| 見るもの | `NAV` → `ALIGN` を経て `AT_PANEL` になるか。到着時のズレ |
| **合格** | 途中で停止せず盤前に到着し、向きも合う（登録時の向きとの差が目視で分かるほど大きくない） |
| 記録 | 到着までの時間: ____ 秒 ／ 到着位置のズレ（実測できれば）: ____ cm ／ 向きのズレ: ____ ° |

> 到着判定は xy 0.25m・向き 0.25rad（≈14°）に調整済み（2026-09-11 WS-9AJ）。
> 低速域で機体がほとんど動かなくなる（モーター不感帯）様子が見えたら記録する（未解決の観察事項）。

### T-7. 当日 — 障害物によるBLOCKEDと自動再開 ★最大の関門②

| | |
| --- | --- |
| やること | 移動中の進路上に障害物（台車・箱）を置く |
| 見るもの | 自動減速・停止 → `BLOCKED` 表示 → 障害物を退けたあとの挙動 |
| **合格** | 障害物に接触せず停止し、退けてから**自動で**（数秒〜十数秒以内、または「再検索」を押して）再計算・再開する |
| 記録 | 停止から接触までの余裕（目視）: ____ cm ／ 退けてから再開までの時間: ____ 秒 ／ 「再検索」を押した回数: ____ 回 |

> 過去に「障害物を退けても永久にBLOCKEDのまま」というバグが実機で見つかり修正済みだが
> **実機での再現テストは未実施**。ここが今回唯一無二の初検証ポイント。

### T-12. 安全機能 — 人の横断・接近での自動減速・停止

| | |
| --- | --- |
| やること | 自動移動中、進路前方（機体正面±29°程度）を人が横切る／接近する |
| 見るもの | 接触前に減速・停止するか |
| **合格** | 機体前面から約15cm以内に近づく前に停止する。人が離れたら自動で再開する |
| 記録 | 停止したか: ____ ／ 目視での最接近距離: ____ cm |

> **安全上の注意**: 役の人は自分から離れられる速度・体勢で行い、停止を確認する前に
> 距離を詰めない。物理非常停止ボタンを押せる人を必ず並走させる。

| | |
| --- | --- |
| やること | 任意の自動移動中に物理非常停止ボタンを押す |

| **合格** | 押した瞬間に停止する。解除後、元のモード（行き先選択等）に戻れる、またはメインメニューへ安全に戻れる |
| 記録 | 停止までの体感: ____ ／ 解除後の戻り先: ____________ |

## 5. 中止の条件

次のどれかに当たったら**その場で試験を止めて報告する**。無理に続けない。

- ロボットが人・壁に向かって進み、「停止」でも物理非常停止でも止まらない
- 障害物・人の接近を検知できず停止せずに接触した（またはしそうになった）
- 「非常停止中」が短時間に3回以上繰り返し出る
- 会場地図が壊れる、または自己位置が大きくズレたまま気づかず走り続けている
- `ESP32_DISCONNECTED` が消えない
