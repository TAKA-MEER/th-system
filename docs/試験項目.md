### T-11. 校正（画面 S-40・`WP-MAINT-02`）

操作は [使い方.md](使い方.md) §3-9。**周囲 2 m 以上の空き**、メジャー（直進）と分度器（旋回）、床にスタート位置と向きの印。
**許容範囲がまだ決まっていないので、そのままだと検証は必ず NG になる。**起動後に次を入れてから始める（値は仮。結果を見て決める）。

```bash
ros2 param set /calib_runner calib_linear_tolerance_ratio 0.05
ros2 param set /calib_runner calib_rotation_tolerance_deg 5.0
```

| | |
| --- | --- |
| やること | ①**直進**: Step 1〜4 を通す（1 m 走る → 実測を入力 → 適用して検証走行 → 実測を入力）②**旋回**: 同じく（180° 回る）③途中で「中断」を押す（直進の Step 2 の走行中に 1 回）④**IMU**: 案内どおり 8 の字に動かして 3/3 まで ⑤「履歴」で 1 つ前の値に戻せるか ⑥**LiDAR 死角**: ライブスキャン上でアルミ角柱の写り込みをなぞって選び、適用 → 検証 → 確定（2026-10-01 追加） |
