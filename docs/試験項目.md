### T-3. 盤前到着の許容差（0.12 m／0.12 rad）

| | |
| --- | --- |
| やること | 待機場所 → 盤 A → 盤 B → 待機場所 を **2 周**（時間があれば 3 周）。**到着するたびに**機体の位置を読み、登録してあるピンの座標と比べる（読み方は [使い方.md](使い方.md) §3-7c） |
| 合格 | **全到着で止まりきる**（目標付近で前後・左右に行ったり来たりを 10 秒以上続けない）。**途中で `BLOCKED`（「経路が見つかりません」の帯）にならない** |
| 記録 | 到着ごとに: 行き先／到着までの秒数／到着時の x, y, yaw ／ ピンの x, y, yaw ／ 位置のずれ（cm）・向きのずれ（°）／ 目標付近で揺れたか |

| 周 | 行き先 | 秒 | 到着時 x, y, yaw | ピン x, y, yaw | ずれ cm / ° | 揺れ |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 盤 A | | | | | |
| 1 | 盤 B | | | | | |
| 1 | 待機場所 | | | | | |
| 2 | 盤 A | | | | | |
| 2 | 盤 B | | | | | |
| 2 | 待機場所 | | | | | |

**見方**: ずれが 12 cm・7°（0.12 rad）以内に収まり、揺れも無ければ今の値を維持。揺れたり時間がかかったりすれば、0.12 と 0.25 の間で戻す判断材料になる。
**テープの印とは比べない**（それは登録の誤差まで混ざる。到着判定だけを見たいので、比べる相手は登録ピン）。

## 5. 中止の条件

- ロボットが人・壁に向かって進み、「停止」でも物理非常停止でも止まらない
- T-1 で推定を止めても止まらず、そのまま自律走行を続ける（**物理非常停止で止め、以降の自律走行はやめる**）
- 「非常停止中」が短時間に 3 回以上繰り返し出る
- `ESP32_DISCONNECTED` が消えない
